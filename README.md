# Minhas criações — anotações de estudos

Este repositório guarda anotações feitas durante meus estudos iniciais de desenvolvimento web e programação criativa. Os documentos são registros de aprendizado, **não projetos ou aplicações completas**.

## Conteúdo

### [Anotações de HTML e CSS](Anota%C3%A7%C3%B5es%20HTML%20e%20CSS%20%281%29.txt)

Resumo pessoal sobre estrutura básica de páginas HTML, tags semânticas, links, imagens, listas e propriedades CSS como cores, espaçamentos, bordas e posicionamento.

### [Comandos e observações de p5.js](p5_comandos%20e%20observa%C3%A7%C3%B5es.txt)

Notas sobre variáveis, condicionais, desenho, cores, listas, imagens, sons e organização de funções no p5.js. O arquivo também registra ideias e referências para montar um portfólio de estudos.

## Observações

- Os dois arquivos `.txt` foram preservados **sem alterações**, incluindo a redação original.
- São anotações de uma etapa anterior dos estudos; podem conter simplificações, erros de digitação ou conceitos que mereçam revisão.
- Para documentação oficial, consulte as referências das tecnologias: [MDN Web Docs](https://developer.mozilla.org/pt-BR/) e [p5.js](https://p5js.org/reference/).
